# 逻辑工坊 · Logic Lab

一个中文经典逻辑工作台。通过按钮输入命题变量、量词、谓词、定义符号与等词，填写前提和结论，检验论证是否有效，并展示自然演绎证明过程。命题逻辑保留真值表；一阶逻辑使用语法证明搜索，并在找到有限反例模型时给出中文解释。验证后可下载“前提–结论文档”，无论有效、无效或尚未判定。

## 使用

- 点击前提或结论输入框，再点击左侧变量、个体词项、连接词或量词按钮；也支持直接键盘输入。
- 量词示例：`∀x (P(x) → Q(x))`、`∃x P(x)`、`∀x ∃y R(x, y)`。大写字母是谓词或命题；`x y z u v w` 是个体变量，其他小写字母是常项。
- 定义与等词示例：`P ≝ Q ∧ R`、`a = b`、`a ≠ b`、`∀x (x = a → P(x))`。`≝`（别名 `≔`、`≜`、`:=`、`=def`、`=df`）按双向等价处理；`=`/`==` 与 `≠`/`!=`/`/=` 只比较个体项。
- 点击「验证论证」，或按 `Ctrl / ⌘ + Enter`。
- 有效论证不存在「所有前提为真、结论为假」的赋值；无效论证会显示具体反例。
- 命题论证保留可筛选、可导出 CSV 的真值表，并附加自然演绎证明。
- 一阶论证显示自然演绎证明：每一步列出公式、规则、依赖行号与子证明缩进；量词规则附带本征常项条件。
- 「命题含义」可为变量设置中文语句；修改含义不改变逻辑形式。
- 提供肯定前件、否定后件、假言三段论、二难推理、常见形式谬误，以及全称/存在量词推理与量词顺序谬误等示例。
- 输入自动保存在当前浏览器；所有计算和文档生成都在本地完成，不上传公式。

支持 `¬ ∧ ∨ → ↔ ⊕ ↑ ↓ ← ( ) ⊤ ⊥ ∀ ∃ ≝ ≔ = ≠`。键盘别名包括 `! ~ && & || | -> => <-> <=> ^ <- ⊻ ≢ ⊼ ⊽ ⊃ ≡ forall exists := =def =df == != /=`。命题连接词优先级为 `¬ > ∧/↑ > ∨/⊕/↓ > →/← > ↔/≝`；相等/不相等是原子公式，量词与 `¬` 同级，作用域默认为紧随其后的公式，复杂作用域请加括号。公式等价请用 `↔`、`≡` 或 `<->`；`=` 现在表示个体项相等，不再作为 `↔` 的别名。

## 判定方式与边界

- **命题逻辑**：穷举真值表仍是权威判定；最多 10 个不同命题变量、8 条前提，每条公式最多 500 个字符。有效论证同时尝试给出自然演绎证明。
- **一阶逻辑（含等词、无函数）**：先做有界自然演绎证明搜索；找到证明即判有效。未找到证明时，再搜索小论域有限反例模型；找到“前提全真、结论为假”的模型即判无效。两者都没有时显示「尚未判定」，绝不把搜索失败说成无效。
- 自然演绎规则包括前提、假设、合取/析取/蕴涵/等价/定义引入与消除、否定引入/消除、经典反证法、爆炸原理、全称引入/消除、存在引入/消除，以及等词自反 `=I` 与替换 `=E`。证明返回前会经过独立规则校验；等词替换会检查自由出现与变量捕获。
- 有限反例模型默认搜索论域大小 1–3、原子谓词实例数与映射数有上限。它用于给出可核对的反例，不是完整的一阶逻辑判定过程。
- 这是经典逻辑工具，不支持函数项、模态、高阶量词或无穷论域上的完备语义判定。定义符号不执行赋值或全局定义注册，只作为当前论证中的双向等价公式。有效性不意味着前提真实；矛盾前提导致的空真有效会单独提示。

## 真值表不是固定 16×16

真值表的行数由命题变量数决定：`行数 = 2^变量数`。列数由当前论证决定：`赋值序号 + 变量列 + 每条前提列 + 结论列 + 结果列`。

例如 4 个变量、2 条前提时，是 **16 行 × 9 列**；2 个变量、2 条前提时，是 **4 行 × 7 列**。只有变量数恰好为 4 时才有 16 行。页面和下载文档都会显示实际行列数。

## 下载前提–结论文档

验证后，右侧“前提–结论文档”卡片可下载当前论证。有效、无效、尚未判定都支持。格式可选：

- Markdown (`.md`)
- 网页文档 (`.html`)
- 纯文本 (`.txt`)

文档包含：

- 全部符号前提和结论；启用命题含义时附中文直译。
- 判定结果与判定说明。
- 有自然演绎证明时附证明步骤。
- 命题逻辑有效但没有自然演绎证明步骤时，附真值表判定说明和完整真值表，不伪造自然演绎证明。
- 无效论证附反例直译；一阶无效论证附有限反例模型细节。
- 尚未判定的一阶论证附搜索边界，明确说明“未找到证明不等于无效”。

## 本地运行

需要 Node.js 20 或更新版本。核心逻辑和静态服务器无第三方运行时依赖。

```sh
npm run dev
# 打开 http://localhost:3000
PORT=8080 npm run dev  # 自定义端口
```

## 检查

```sh
npm test
npm run check
```

42 项单元测试覆盖连接词语义、优先级、括号、键盘别名、语法错误、2,300 个随机公式的格式化往返、中文翻译、有效与无效论证、反例、空真有效、重言式、计算限制、量词/定义/等词解析与捕获避免替换、自然演绎证明及校验、等词替换校验、有限反例模型，以及前提–结论文档导出、真值表行列数、证明缺失时的真值表证书和 HTML 转义。

## 静态部署

入口是 `index.html`，应用资源使用相对路径，不需要后端或站点密钥。GitHub Pages 工作流只上传静态应用文件。由于使用 ES Modules，请通过 HTTP 访问，而不是双击以 `file://` 打开。

## 文件

- `index.html`：中文界面、符号面板、使用指南。
- `styles.css`：响应式布局与可访问性样式。
- `app.js`：输入与光标、论证编辑、真值表、保存与导出。
- `logic.js`：命题逻辑 tokenizer、递归下降解析器、求值器、翻译器和穷举有效性判定。
- `fol.js`：一阶逻辑语法树、量词作用域、定义/等词、格式化、替换与翻译。
- `natural-deduction.js`：有界自然演绎证明搜索、规则校验与证明文本。
- `countermodel.js`：有界有限反例模型搜索。
- `argument.js`：命题/一阶统一分析入口。
- `server.mjs`：零依赖本地静态服务器。
- `explanation.js`：无效论证的确定性反例叙述。
- `argument-document.js`：前提–结论文档生成与下载格式。
- `tests/`：Node.js 原生测试。

公式通过明确的语法树解析，不使用 `eval` 或 `new Function`；用户输入在渲染时进行 HTML 转义。
