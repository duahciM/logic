# 逻辑工坊 · Logic Lab

一个中文命题逻辑工作台。通过按钮输入命题变量与逻辑符号，填写前提和结论，检验论证是否有效，并将公式翻译成自然语言。

## 使用

- 点击前提或结论输入框，再点击左侧变量、连接词按钮；也支持直接键盘输入。
- 点击「验证论证」，或按 `Ctrl / ⌘ + Enter`。
- 有效论证不存在「所有前提为真、结论为假」的赋值；无效论证会显示具体反例。
- 真值表可以筛选前提全真的行、反例，也可以导出完整 CSV。
- 「编辑含义」可为变量设置中文语句；修改含义不改变逻辑形式。
- 提供肯定前件、否定后件、假言三段论、二难推理及常见形式谬误等示例。
- 输入自动保存在当前浏览器；不上传到服务器。

支持 `¬ ∧ ∨ → ↔ ( ) ⊤ ⊥`，以及键盘别名 `! ~ && & || | -> => <-> <=> =`。优先级为 `¬ > ∧ > ∨ > → > ↔`，蕴涵右结合。

这是**经典二值命题逻辑**工具：最多 10 个不同变量（1,024 行真值表）、8 条前提，每条公式最多 500 个字符。不支持谓词、量词或模态逻辑。有效性不意味着前提真实；矛盾前提导致的空真有效会单独提示。翻译采用确定性的语法树转换，不调用 AI。

## 本地运行

需要 Node.js 20 或更新版本，无运行时依赖，无需安装 npm 包。

```sh
npm run dev
# 打开 http://localhost:3000
PORT=8080 npm run dev  # 自定义端口
```

## 检查

```sh
npm test
npm run check
```

单元测试覆盖连接词语义、优先级、括号、键盘别名、语法错误、300 个随机公式的格式化往返、中文翻译、有效与无效论证、反例、空真有效、重言式以及计算限制。

## 静态部署

直接用任意静态 HTTP 服务托管本目录即可。入口是 `index.html`，所有资源使用相对路径，不需要构建、后端、密钥或外部 CDN。

仓库已有 GitHub Pages 工作流：推送到 `main` 后会部署站点。也可在 GitHub Actions 中手动运行「Deploy static content to Pages」。由于使用 ES Modules，请通过 HTTP 访问，而不是双击以 `file://` 打开。

## 文件

- `index.html`：中文界面、符号面板、使用指南。
- `styles.css`：响应式布局与可访问性样式。
- `app.js`：输入与光标、论证编辑、翻译、真值表、保存与导出。
- `logic.js`：独立的 tokenizer、递归下降解析器、求值器、翻译器和穷举有效性判定。
- `server.mjs`：零依赖本地静态服务器。
- `tests/logic.test.js`：Node.js 原生测试。

公式通过明确的语法树解析，不使用 `eval` 或 `new Function`；用户输入在渲染时进行 HTML 转义。
